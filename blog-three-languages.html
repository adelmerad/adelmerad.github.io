One page, three languages: a trilingual site without a framework Une page, trois langues : un site trilingue sans frameworkصفحة واحدة بثلاث لغات: موقع ثلاثي اللغة دون إطار عمل

The site you are reading speaks English, French and Arabic, with no framework, no build step and no translation library. Here is how it works, the right-to-left traps I fell into, and what this approach really costs. Le site que vous lisez parle anglais, français et arabe, sans framework, sans étape de build et sans bibliothèque de traduction. Voici comment il fonctionne, les pièges de l'écriture de droite à gauche dans lesquels je suis tombé, et ce que cette approche coûte vraiment.الموقع الذي تقرؤه يتحدث الإنجليزية والفرنسية والعربية، دون إطار عمل ودون مرحلة بناء ودون مكتبة ترجمة. إليك كيف يعمل، وفخاخ الكتابة من اليمين إلى اليسار التي وقعت فيها، وما تكلّفه هذه الطريقة فعلاً.

Why three languagesPourquoi trois languesلماذا ثلاث لغات

In Algeria, a recruiter may read English, a local company often works in French, and Arabic is the language many people read most naturally. I wanted the same portfolio to work for all of them. The site is plain HTML, CSS and a little JavaScript on GitHub Pages: 22 pages, and more than 900 pieces of text, each written three times. En Algérie, un recruteur peut lire l'anglais, une entreprise locale travaille souvent en français, et l'arabe est la langue que beaucoup lisent le plus naturellement. Je voulais que le même portfolio marche pour tous. Le site est du HTML, du CSS et un peu de JavaScript sur GitHub Pages : 22 pages, et plus de 900 textes, chacun écrit trois fois.في الجزائر، قد يقرأ مسؤول التوظيف بالإنجليزية، وكثيراً ما تعمل الشركات المحلية بالفرنسية، والعربية هي اللغة التي يقرؤها كثيرون بشكل أكثر طبيعية. أردت أن يناسب ملف الأعمال نفسه الجميع. الموقع مكتوب بـ HTML وCSS وقليل من JavaScript على GitHub Pages: 22 صفحة، وأكثر من 900 نص، كل منها مكتوب ثلاث مرات.

The trick: everything is there, CSS shows oneL'astuce : tout est là, le CSS en montre uneالفكرة: كل شيء موجود، وCSS يُظهر لغة واحدة

Every text is written three times, side by side, each in a span with a lang attribute: Chaque texte est écrit trois fois, côte à côte, chacun dans un span avec un attribut lang :كل نص مكتوب ثلاث مرات، جنباً إلى جنب، كل نسخة في span بخاصية lang:

<h2>
  <span lang="en">Projects</span>
  <span lang="fr">Projets</span>
  <span lang="ar">المشاريع</span>
</h2>

The html element carries the chosen language, and one CSS rule hides the two others: L'élément html porte la langue choisie, et une seule règle CSS cache les deux autres :يحمل عنصر html اللغة المختارة، وقاعدة CSS واحدة تُخفي اللغتين الأخريين:

html[data-lang="en"] body [lang="fr"], html[data-lang="en"] body [lang="ar"],
html[data-lang="fr"] body [lang="en"], html[data-lang="fr"] body [lang="ar"],
html[data-lang="ar"] body [lang="en"], html[data-lang="ar"] body [lang="fr"] {
  display: none !important;
}

Switching language is just changing that attribute: no page reload, no text to fetch, nothing to re-render. And the lang attribute is not only a CSS hook. It tells screen readers which voice to use, and it lets the browser pick the right font: the font list falls back to IBM Plex Sans Arabic for Arabic letters. Changer de langue, c'est juste changer cet attribut : pas de rechargement, pas de texte à télécharger, rien à réafficher. Et l'attribut lang n'est pas qu'un repère pour le CSS. Il indique aux lecteurs d'écran quelle voix utiliser, et il permet au navigateur de choisir la bonne police : la liste de polices se rabat sur IBM Plex Sans Arabic pour les lettres arabes.تغيير اللغة هو مجرد تغيير هذه الخاصية: لا إعادة تحميل للصفحة، ولا نص يجب جلبه، ولا شيء يُعاد رسمه. وخاصية lang ليست مجرد علامة لـ CSS. فهي تخبر قارئات الشاشة بالصوت الذي يجب استعماله، وتسمح للمتصفح باختيار الخط المناسب: إذ تنتقل قائمة الخطوط إلى IBM Plex Sans Arabic للحروف العربية.

No flash of the wrong languagePas de flash de la mauvaise langueلا وميض للغة الخطأ

The visitor's choice is saved in localStorage. If it were applied by the main script at the end of the page, an Arabic reader would first see the English page, then watch it jump to the right. So a tiny script in the <head> runs before anything is painted and sets the language, the direction and the theme. Its reads are wrapped in try, because storage can throw in private windows: the page must still work, in English. Le choix du visiteur est enregistré dans localStorage. S'il était appliqué par le script principal à la fin de la page, un lecteur arabophone verrait d'abord la page en anglais, puis la verrait basculer vers la droite. Donc un tout petit script dans le <head> s'exécute avant tout affichage et fixe la langue, la direction et le thème. Ses lectures sont dans un try, car le stockage peut lever une erreur en navigation privée : la page doit quand même marcher, en anglais.يُحفظ اختيار الزائر في localStorage. ولو طُبّق بالسكربت الرئيسي في آخر الصفحة، لرأى القارئ العربي الصفحة بالإنجليزية أولاً، ثم رآها تنقلب نحو اليمين. لذلك يعمل سكربت صغير جداً في <head> قبل رسم أي شيء، فيضبط اللغة والاتجاه والمظهر. وقراءاته محاطة بـ try، لأن التخزين قد يرمي خطأً في التصفح الخاص: يجب أن تعمل الصفحة رغم ذلك، بالإنجليزية.

Right to leftDe droite à gaucheمن اليمين إلى اليسار

Setting dir="rtl" on the page flips most of the layout for free: text alignment, the order of flex and grid items. The rest needs care: Mettre dir="rtl" sur la page inverse gratuitement la plus grande partie de la mise en page : l'alignement du texte, l'ordre des éléments flex et grid. Le reste demande de l'attention :وضع dir="rtl" على الصفحة يقلب معظم التخطيط مجاناً: محاذاة النص، وترتيب عناصر flex وgrid. أما الباقي فيحتاج إلى عناية:

  • Logical properties. padding-left stays on the left in Arabic. padding-inline-start and inset-inline-start follow the reading direction, so on a phone the timeline's line and dots move to the right side on their own.Les propriétés logiques. padding-left reste à gauche en arabe. padding-inline-start et inset-inline-start suivent le sens de lecture : sur téléphone, la ligne et les points de la frise passent tout seuls à droite.الخصائص المنطقية. تبقى padding-left على اليسار في العربية. أما padding-inline-start وinset-inline-start فتتبعان اتجاه القراءة، فعلى الهاتف ينتقل خط المسار الزمني ونقاطه إلى اليمين تلقائياً.
  • Arrows. "Read the article →" must point left in Arabic, so arrows are mirrored with transform: scaleX(-1).Les flèches. « Lire l'article → » doit pointer vers la gauche en arabe, donc les flèches sont retournées avec transform: scaleX(-1).الأسهم. يجب أن يشير سهم «اقرأ المقال» إلى اليسار في العربية، لذلك تُعكس الأسهم بـ transform: scaleX(-1).
  • Code stays left to right. Code blocks keep direction: ltr even inside an Arabic page.Le code reste de gauche à droite. Les blocs de code gardent direction: ltr, même dans une page en arabe.تبقى الشيفرة من اليسار إلى اليمين. تحتفظ كتل الشيفرة بـ direction: ltr حتى داخل صفحة عربية.
  • Typography. Arabic letters join each other, and letter-spacing breaks those joins, so it is set to 0 in Arabic. Arabic has no italics either: the tagline's highlighted words are bold instead.La typographie. Les lettres arabes sont liées entre elles, et letter-spacing casse ces liaisons : il est donc mis à 0 en arabe. L'arabe n'a pas non plus d'italique : les mots mis en valeur dans la phrase d'accroche sont en gras à la place.الطباعة. الحروف العربية متصلة ببعضها، وletter-spacing يكسر هذا الاتصال، لذلك يُضبط على 0 في العربية. كما لا توجد كتابة مائلة في العربية: الكلمات البارزة في العبارة الرئيسية تُكتب بخط عريض بدلاً من ذلك.

The bidirectional text trapsLes pièges du texte bidirectionnelفخاخ النص ثنائي الاتجاه

The hardest bugs came from mixing Arabic with Latin text and numbers. Browsers use the Unicode bidirectional algorithm: letters have a direction, but spaces, punctuation, + and parentheses are "neutral" and take the direction of the text around them. Three real examples from my articles: Les bugs les plus difficiles venaient du mélange de l'arabe avec du texte latin et des nombres. Les navigateurs utilisent l'algorithme bidirectionnel Unicode : les lettres ont une direction, mais les espaces, la ponctuation, le + et les parenthèses sont « neutres » et prennent la direction du texte qui les entoure. Trois exemples réels tirés de mes articles :جاءت أصعب الأخطاء من خلط العربية بنص لاتيني وأرقام. تستعمل المتصفحات خوارزمية Unicode ثنائية الاتجاه: للحروف اتجاه، أما المسافات وعلامات الترقيم و+ والأقواس فهي «محايدة» وتأخذ اتجاه النص المحيط بها. ثلاثة أمثلة حقيقية من مقالاتي:

  • counter++ became ++counter in an Arabic heading. The two + signs at the end of the Latin word were neutral, so they followed the Arabic direction and jumped to the other side. Wrapping the word in <bdi> isolates it and keeps its own direction.counter++ devenait ++counter dans un titre en arabe. Les deux + à la fin du mot latin étaient neutres : ils suivaient la direction arabe et sautaient de l'autre côté. Entourer le mot d'un <bdi> l'isole et lui garde sa propre direction.صار counter++ يظهر ++counter في عنوان عربي. كانت علامتا + في آخر الكلمة اللاتينية محايدتين، فاتبعتا الاتجاه العربي وقفزتا إلى الجهة الأخرى. إحاطة الكلمة بـ <bdi> تعزلها وتحفظ اتجاهها الخاص.
  • Numbers in tables came out reversed. In a results table, cells mixing numbers and units were reordered in Arabic. Number cells now use direction: ltr; unicode-bidi: isolate, right-aligned so the column still reads naturally.Les nombres des tableaux sortaient à l'envers. Dans un tableau de résultats, les cellules qui mélangeaient nombres et unités étaient réordonnées en arabe. Les cellules de nombres utilisent maintenant direction: ltr; unicode-bidi: isolate, alignées à droite pour que la colonne se lise toujours naturellement.ظهرت الأرقام في الجداول معكوسة. في جدول نتائج، كانت الخلايا التي تخلط الأرقام بالوحدات يُعاد ترتيبها في العربية. أصبحت خلايا الأرقام تستعمل direction: ltr; unicode-bidi: isolate، مع محاذاة إلى اليمين كي يُقرأ العمود بشكل طبيعي.
  • Parentheses around an English term broke at the end of a line. When "(race condition)" was split across two lines in Arabic, the parentheses ended up on the wrong sides. I rephrased the sentence without parentheses and kept the term on one line with white-space: nowrap.Des parenthèses autour d'un terme anglais se cassaient en fin de ligne. Quand « (race condition) » était coupé sur deux lignes en arabe, les parenthèses se retrouvaient du mauvais côté. J'ai reformulé la phrase sans parenthèses et gardé le terme sur une seule ligne avec white-space: nowrap.انكسرت أقواس حول مصطلح إنجليزي في آخر السطر. عندما انقسم «race condition» بين قوسين على سطرين في العربية، انتهت الأقواس في الجهات الخطأ. أعدت صياغة الجملة دون أقواس، وأبقيت المصطلح على سطر واحد بـ white-space: nowrap.

And while I was writing this very article, it happened again: on a phone, in Arabic, the inline code white-space: nowrap wrapped into "white-" and ".space", in the wrong order. Inline code inside Arabic text is now laid out as one small left-to-right box, so when it has to wrap, its lines stay in order. Et pendant que j'écrivais cet article, c'est encore arrivé : sur téléphone, en arabe, le code white-space: nowrap s'est coupé en « white- » et « .space », dans le mauvais ordre. Le code en ligne dans un texte arabe est maintenant affiché comme une petite boîte de gauche à droite : quand il doit passer à la ligne, ses lignes restent dans l'ordre.وبينما كنت أكتب هذا المقال نفسه، حدث ذلك مجدداً: على الهاتف وبالعربية، انقسمت الشيفرة white-space: nowrap إلى «white-» و«.space» بترتيب خاطئ. أصبحت الشيفرة المضمّنة داخل النص العربي تُعرض الآن كصندوق صغير من اليسار إلى اليمين، فإذا اضطرت إلى الانتقال إلى سطر جديد بقيت أسطرها مرتبة.

None of these show up in English or French. The only way I found them was to look at every article in Arabic, on a phone-sized screen, where lines break the most. Aucun de ces bugs n'apparaît en anglais ou en français. La seule façon de les trouver a été de regarder chaque article en arabe, sur un écran de la taille d'un téléphone, là où les lignes se coupent le plus.لا يظهر أيّ من هذه الأخطاء بالإنجليزية أو الفرنسية. والطريقة الوحيدة التي وجدتها لاكتشافها هي مراجعة كل مقال بالعربية، على شاشة بحجم الهاتف، حيث تنكسر الأسطر أكثر.

A trap of my own makingUn piège que je me suis tendu moi-mêmeفخ صنعته بنفسي

The Arabic button in the language switch shows the letter "ع". A screen reader announces it as a lone letter, so it needs a proper name. The obvious fix would be lang="ar" on the button... and the CSS rule above would then hide the Arabic button whenever the page is in English or French, exactly when you need it. The button gets an aria-label instead. Le bouton arabe du sélecteur de langue affiche la lettre « ع ». Un lecteur d'écran l'annonce comme une lettre isolée, donc il lui faut un vrai nom. La correction évidente serait lang="ar" sur le bouton… et la règle CSS ci-dessus cacherait alors le bouton arabe dès que la page est en anglais ou en français, c'est-à-dire justement quand on en a besoin. Le bouton reçoit un aria-label à la place.يعرض زر العربية في محدد اللغة الحرف «ع». تنطقه قارئات الشاشة كحرف منفرد، لذلك يحتاج إلى اسم حقيقي. الحل البديهي هو وضع lang="ar" على الزر... لكن قاعدة CSS السابقة ستُخفي عندها زر العربية كلما كانت الصفحة بالإنجليزية أو الفرنسية، أي بالضبط عندما نحتاج إليه. لذلك يحصل الزر على aria-label بدلاً من ذلك.

What this approach costsCe que coûte cette approcheما تكلّفه هذه الطريقة

  • Weight. Every visitor downloads all three languages. For the home page, that is 9.8 KB compressed instead of about 5.3 KB for English alone. Acceptable for a portfolio, not for a site with thousands of pages.Le poids. Chaque visiteur télécharge les trois langues. Pour la page d'accueil, ça fait 9,8 Ko compressés au lieu d'environ 5,3 Ko pour l'anglais seul. Acceptable pour un portfolio, pas pour un site de milliers de pages.الحجم. يحمّل كل زائر اللغات الثلاث. بالنسبة للصفحة الرئيسية، هذا يعني 9.8 كيلوبايت مضغوطة بدل نحو 5.3 كيلوبايت للإنجليزية وحدها. مقبول لملف أعمال، لا لموقع من آلاف الصفحات.
  • Search engines. Google renders the page with no saved preference, so it sees the English version; the French and Arabic text is hidden and has little chance of appearing in search results. For the medical imaging center's website I did the opposite: each page exists twice, at its own URL, linked with hreflang, precisely so that the Arabic page can be found by someone searching in Arabic. A portfolio is found through links more than through search, so here I chose simplicity.Les moteurs de recherche. Google affiche la page sans préférence enregistrée, donc il voit la version anglaise ; le texte français et arabe est caché et a peu de chances d'apparaître dans les résultats. Pour le site du centre d'imagerie médicale, j'ai fait l'inverse : chaque page existe deux fois, à sa propre adresse, reliées par hreflang, justement pour qu'on trouve la page arabe en cherchant en arabe. Un portfolio se trouve plus par des liens que par la recherche, donc ici j'ai choisi la simplicité.محركات البحث. يعرض Google الصفحة دون أي تفضيل محفوظ، فيرى النسخة الإنجليزية؛ أما النص الفرنسي والعربي فمخفي وفرصته ضعيفة في الظهور في نتائج البحث. في موقع مركز التصوير الطبي فعلت العكس: كل صفحة موجودة مرتين، بعنوان خاص بها، مربوطتين بـ hreflang، تحديداً كي يجد من يبحث بالعربية الصفحة العربية. أما ملف الأعمال فيُعثر عليه عبر الروابط أكثر من البحث، لذلك اخترت هنا البساطة.
  • Shared links. The language lived only in the visitor's browser, so a link I sent to an Arabic-speaking friend opened in whatever language their browser had saved, usually English.Les liens partagés. La langue n'existait que dans le navigateur du visiteur : un lien que j'envoyais à un ami arabophone s'ouvrait dans la langue enregistrée par son navigateur, en général l'anglais.الروابط المشتركة. كانت اللغة محفوظة في متصفح الزائر فقط، فكان الرابط الذي أرسله إلى صديق يتحدث العربية يُفتح باللغة المحفوظة في متصفحه، وغالباً الإنجليزية.

What I changed after this reviewCe que j'ai changé après cette relectureما الذي غيّرته بعد هذه المراجعة

  • Links can carry a language. ?lang=ar opens any page in Arabic and remembers it, and switching language updates the address bar, so a copied link opens in the language you were reading. Unknown values are ignored.Les liens peuvent porter une langue. ?lang=ar ouvre n'importe quelle page en arabe et s'en souvient, et changer de langue met à jour la barre d'adresse : un lien copié s'ouvre dans la langue que vous lisiez. Les valeurs inconnues sont ignorées.يمكن للروابط أن تحمل لغة. يفتح ?lang=ar أي صفحة بالعربية ويحفظها، وتغيير اللغة يحدّث شريط العنوان، فيُفتح الرابط المنسوخ باللغة التي كنت تقرأ بها. والقيم غير المعروفة تُتجاهل.
  • One script instead of 21 copies. The early script was pasted in every page. It now lives in one file, boot.js, still loaded in the <head> before paint.Un script au lieu de 21 copies. Le script de démarrage était collé dans chaque page. Il est maintenant dans un seul fichier, boot.js, toujours chargé dans le <head> avant l'affichage.سكربت واحد بدل 21 نسخة. كان سكربت البداية ملصقاً في كل صفحة. أصبح الآن في ملف واحد، boot.js، ويُحمَّل دائماً في <head> قبل الرسم.
  • Labels for screen readers follow the language. The theme, menu and language buttons were labelled in English on every page; they now follow the current language, each language button is named in its own language, and the selected one is marked with aria-pressed.Les libellés pour lecteurs d'écran suivent la langue. Les boutons du thème, du menu et des langues étaient nommés en anglais sur toutes les pages ; ils suivent maintenant la langue courante, chaque bouton de langue est nommé dans sa propre langue, et celui qui est choisi est marqué avec aria-pressed.تسميات قارئات الشاشة تتبع اللغة. كانت أزرار المظهر والقائمة واللغات مسمّاة بالإنجليزية في كل الصفحات؛ أصبحت الآن تتبع اللغة الحالية، وكل زر لغة مسمّى بلغته، والزر المختار مُعلَّم بـ aria-pressed.
  • Shared styles. The table styles that keep numbers left to right were copied into two articles; they now live in the main stylesheet. Inline code in Arabic wraps as one box. And the 404 page, which GitHub Pages can serve at any depth, loads the new script with an absolute path.Des styles partagés. Les styles de tableau qui gardent les nombres de gauche à droite étaient copiés dans deux articles ; ils sont maintenant dans la feuille de style principale. Le code en ligne en arabe se replie en un seul bloc. Et la page 404, que GitHub Pages peut servir à n'importe quelle profondeur, charge le nouveau script avec un chemin absolu.أنماط مشتركة. كانت أنماط الجداول التي تُبقي الأرقام من اليسار إلى اليمين منسوخة في مقالين؛ أصبحت الآن في ملف الأنماط الرئيسي. وأصبحت الشيفرة المضمّنة في العربية تنتقل إلى السطر كصندوق واحد. كما أن صفحة 404، التي قد يعرضها GitHub Pages على أي عمق، تحمّل السكربت الجديد بمسار مطلق.

TakeawaysÀ retenirالخلاصة

  • For a small site, all languages in the page plus one CSS rule is simple and fast. It does not scale to large sites or to search in every language.Pour un petit site, toutes les langues dans la page plus une règle CSS, c'est simple et rapide. Ça ne passe pas à l'échelle pour de gros sites, ni pour être trouvé en recherche dans chaque langue.لموقع صغير، وضع كل اللغات في الصفحة مع قاعدة CSS واحدة أمر بسيط وسريع. لكنه لا يصلح للمواقع الكبيرة، ولا للظهور في البحث بكل لغة.
  • Apply the language before the first paint, and never let storage errors break the page.Appliquer la langue avant le premier affichage, et ne jamais laisser une erreur de stockage casser la page.طبّق اللغة قبل أول رسم، ولا تدع أخطاء التخزين تكسر الصفحة أبداً.
  • For right to left, use logical properties and isolate every piece of Latin text, code or number with <bdi> or unicode-bidi: isolate.Pour la droite-à-gauche, utiliser les propriétés logiques et isoler chaque morceau de texte latin, de code ou de nombre avec <bdi> ou unicode-bidi: isolate.للكتابة من اليمين إلى اليسار، استعمل الخصائص المنطقية واعزل كل جزء من نص لاتيني أو شيفرة أو رقم بـ <bdi> أو unicode-bidi: isolate.
