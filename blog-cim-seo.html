Telling Google what the center isDire à Google ce qu'est le centreأن نقول لـ Google ما هو المركز

A search engine reads text, but it understands structured data much better. Each page carries schema.org JSON-LD: the center as a MedicalClinic with its exact location, opening hours, social profiles and the exams it offers. Un moteur de recherche lit du texte, mais il comprend beaucoup mieux des données structurées. Chaque page contient du JSON-LD schema.org : le centre comme MedicalClinic, avec sa position exacte, ses horaires, ses réseaux sociaux et les examens proposés.يقرأ محرك البحث النص، لكنه يفهم البيانات المنظَّمة أفضل بكثير. تحمل كل صفحة بيانات JSON-LD من schema.org: المركز كـ MedicalClinic مع موقعه الدقيق، وأوقات عمله، وحساباته على الشبكات الاجتماعية، والفحوصات التي يقدمها.

On a medical site, a wrong opening time or a wrong preparation instruction is a real problem, so every answer is written by hand, in both languages. Le site a un assistant de discussion, et ce n'est volontairement pas une IA. Measuring what brings patientsMesurer ce qui amène des patientsقياس ما يجلب المرضى

Page views say little. What matters is how many people contact the center, and through which path. One delegated click listener sends a Google Analytics 4 generate_lead event for every WhatsApp or phone link on any page, and the form and the assistant send the same event with their own method: Le nombre de pages vues dit peu de chose. Ce qui compte, c'est combien de personnes contactent le centre, et par quel chemin. Un seul écouteur de clics délégué envoie un événement Google Analytics 4 generate_lead pour chaque lien WhatsApp ou téléphone de n'importe quelle page, et le formulaire comme l'assistant envoient le même événement avec leur propre method :عدد مشاهدات الصفحات لا يقول الكثير. المهم هو كم شخصاً يتصل بالمركز، وعبر أي مسار. مستمع نقرات واحد مفوَّض يرسل حدث Google Analytics 4 باسم generate_lead لكل رابط واتساب أو هاتف في أي صفحة، وترسل الاستمارة والمساعد الحدث نفسه مع قيمة method خاصة بهما:

document.addEventListener('click', function (e) {
  var link = e.target.closest('a[href]');
  if (!link || typeof gtag !== 'function') return;
  var href = link.getAttribute('href');
  if (href.indexOf('wa.me') !== -1) {
    gtag('event', 'generate_lead', { method: 'whatsapp' });
  } else if (href.indexOf('tel:') === 0) {
    gtag('event', 'generate_lead', { method: 'telephone' });
  }
});
// the form sends { method: 'form_whatsapp' }

With one event name and a method parameter, a single report shows which channel works, without adding tracking code to each of the 36 pages. Avec un seul nom d'événement et un paramètre method, un seul rapport montre quel canal fonctionne, sans ajouter de code de suivi sur chacune des 36 pages.باسم حدث واحد ومعامل method، يُظهر تقرير واحد أي قناة تنجح، دون إضافة شيفرة تتبّع إلى كل صفحة من الصفحات الـ 36.

What I would do differentlyCe que je ferais autrementما كنت سأفعله بشكل مختلف

  • A static site generator. "No build step" was simple when the site was a single page. At 36 pages, the header, footer and font tags are copied in every file, and one footer change means editing 36 files. A generator like Eleventy would keep the same static output with shared templates.Un générateur de site statique. « Pas d'étape de build », c'était simple quand le site tenait sur une page. À 36 pages, l'en-tête, le pied de page et les balises de polices sont copiés dans chaque fichier, et un changement du pied de page veut dire modifier 36 fichiers. Un générateur comme Eleventy garderait le même résultat statique avec des gabarits partagés.مولّد مواقع ثابتة. كان «بلا مرحلة بناء» بسيطاً عندما كان الموقع صفحة واحدة. أما مع 36 صفحة، فالترويسة والتذييل ووسوم الخطوط منسوخة في كل ملف، وتغيير واحد في التذييل يعني تعديل 36 ملفاً. ومولّد مثل Eleventy سيحافظ على النتيجة الثابتة نفسها مع قوالب مشتركة.
  • One source for the answers. Opening hours and preparation rules live in the page text, the FAQ structured data and the assistant. Generating all three from one data file would make it impossible for them to disagree.Une seule source pour les réponses. Les horaires et les consignes de préparation se trouvent dans le texte des pages, les données structurées de la FAQ et l'assistant. Générer les trois à partir d'un seul fichier de données rendrait impossible qu'ils se contredisent.مصدر واحد للإجابات. أوقات العمل وتعليمات التحضير موجودة في نص الصفحات، وفي البيانات المنظَّمة للأسئلة الشائعة، وفي المساعد. وتوليد الثلاثة من ملف بيانات واحد سيجعل تناقضها مستحيلاً.
  • Leads are clicks, not messages. The event fires when someone opens WhatsApp, not when they actually send the message. Asking new patients at the front desk how they found the center is still the most reliable measure.Un contact, c'est un clic, pas un message. L'événement part quand quelqu'un ouvre WhatsApp, pas quand il envoie vraiment le message.
